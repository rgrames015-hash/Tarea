# 🎵 Music Wave

**Music Wave** es una página web interactiva diseñada para explorar y disfrutar música de una manera sencilla, moderna y visualmente atractiva.

## ✨ Características

- 🎧 Exploración de diferentes géneros musicales.
- 🔎 Buscador de canciones.
- 🎵 Reproductor musical interactivo.
- ⏮️ Canción anterior y siguiente.
- ❤️ Sistema de canciones favoritas.
- 💾 Guardado de favoritos mediante `localStorage`.
- 🎚️ Barra de progreso del reproductor.
- 🎨 Diseño moderno y adaptable.
- ▶️ Acceso directo a YouTube Music.
- ⌨️ Atajos de teclado para controlar el reproductor.

## 🎶 Canciones incluidas

- **Pop Dreams** — Pop
- **Rock Night** — Rock
- **Bachata Love** — Bachata
- **Summer Beat** — Summer

## 🛠️ Tecnologías utilizadas

- **HTML5** — Estructura de la página.
- **CSS3** — Diseño, estilos, animaciones y responsive.
- **JavaScript** — Interactividad y funcionamiento del reproductor.
